# Planning Wizard 页面设计记录

模式：Operate。视觉以现有 DESIGN.md、Hero 和用户已认可的风格为准。保留背景、字体、暗色、矿物绿和 GSAP 开场，不引入新的视觉主题。

- 导航上方品牌，页面内横向流程进度，摘要保留当前旅行上下文。
- 每页一个大标题与清晰的下一步；宽屏表单与旁侧行政区说明，手机单列。
- 区域组采用原生 details 折叠和横向滚动，酒店精选与更多结果分层。
- 品牌采用文字占位；地图按需展开；不会增加宣传区或固定 AI 浮窗。
- 跨页采用可见默认状态的 GSAP clip reveal；等待为边框扫描动效。
- 保留键盘焦点、滑块键盘操作、显式确认与 reduced-motion。

机械设计检测已执行。输出主要为新操作页面的字号和同色系中间色未登记在 V1 DESIGN.md 的 advisory。当前不据此替换用户指定视觉体系，也未把这些提示当成功能错误。产品背景、核心色、字体和开场保持原设计。
