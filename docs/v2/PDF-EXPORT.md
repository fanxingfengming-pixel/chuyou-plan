# 行程 PDF 导出

在 /plan/route 生成路线后，点击「下载行程 PDF」。直接下载 A4 PDF，无需打印对话框。

- 内容来自点击时 tripDraft 快照，包括日期（明确区分确切日期、范围和模糊日期）、人数、交通方式、住宿筛选偏好、已确认酒店、已加入景点地址、每日路线、用餐建议和核对事项。
- 保留用户调整后的天数及顺序；导出不会重新生成、优化或修改草稿。需要优化时保留提示；空白日标注自由活动。
- 只纳入用户已经选择的酒店与景点，不把 hotelResults、推荐区域或未选择候选变成确认结果。
- 查询报价与模拟数据有明确标注；不计算未确认总价，不表示已订房或订票。现有路线只提供顺序建议，不代表实际道路导航、耗时、开放时间或预约校验。
- 浏览器本地生成，不上传行程。导出模块与中文字体按需加载；首次使用会读取本站约 10.6 MB 的中文字体，加载失败可重试。PDF 完整嵌入中文字体以兼容常见阅读器，文件约 6.5 MB，支持中文文字选择、复制和搜索。字体随站点部署，不依赖外部字体服务。
- 中文字体：Noto Sans SC Regular，官方 Sans2.004 TrueType 字体固定为 400 字重的静态 TTF（制作脚本：scripts/prepare-pdf-font.py），遵循 SIL Open Font License 1.1，完整许可见 public/fonts/OFL.txt。
  来源：https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/Variable/TTF/Subset
- PDF 引擎：pdf-lib 1.17.1 + @pdf-lib/fontkit 1.1.1。
  官方说明：https://pdf-lib.js.org/ 及 https://github.com/Hopding/fontkit

修改后重新导出即可获得新版本。生成与下载状态独立于路线编辑，失败保留草稿。
