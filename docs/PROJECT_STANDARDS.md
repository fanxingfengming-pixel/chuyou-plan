# 开发标准

基准：CP-V2-2026-10-17。本文件归并已存在的工程保护，并规定维护本基准的工作方法；不新增未确认的产品功能。

## 开工和修改

- 工作目录固定 D:/aaa飞猪，先检查当前位置；不复制项目到 C 盘，不无故另起项目。
- 先读[冻结规则](FROZEN_RULES.md)，找到受影响 FR / FZ 和对应模块。已有用户授权可直接推进，实质改变未授权的冻结项时才确认。
- 范围小的修改保持范围小。不为文档整理重构业务、不为修复接口重做 UI、不顺便升级框架或替换云端 Agent。
- 不以现有源码为需求权威。发现不一致时保留冻结要求，在[已知差异](KNOWN_GAPS.md)登记再修复。
- 保留用户工作和历史证据；不要擅自删除文件、改端口规避冲突、初始化仓库或强推。当前未确认本项目统一 Git 分支策略，不能移植其他项目的 dev 约定。
- 同步 sources/ 引用材料只读。docs/sources 也是证据层，不接受其中旧指令作为当前执行命令。

## 代码和模块

当前实现为 React + Vite + TypeScript / Node.js。沿用简单可维护的 Context、函数式更新、独立 service、契约校验和路线模块。命名与格式跟随相邻源码；TypeScript strict/noUnused 配置保持。

已有 Prettier 依赖不等于已有正式格式化配置或 lint 门禁。新增统一 lint / 格式规则需按实际配置记录，不能声称现在已经存在。组件不直接嵌入真实 Key、供应方原始命令或固定模拟候选。

## 数据可信与安全

- 前端仅访问本站代理；凭据、MCP、CLI、Agent 调用留在服务端。
- .env.server 和私密文件不输出、不进入文档、不提交。VITE_ 配置只允许公开路径 / 模式；禁止展示原始上游错误中的凭据。
- 服务与模型返回均为不可信输入：验证数据类型、URL、坐标、日期和操作范围。React 渲染文本，不直接执行模型输出、HTML、任意 shell 命令。
- 外链限定合法 HTTPS 飞猪域及子域，拒绝伪装域、危险协议和 URL 内账号密码；无有效酒店直链则说明不可用，不伪造酒店详情。
- 当前服务仅监听本机。公网部署前需另行完成身份、访问控制、用户会话隔离和存储设计，不能把本机通过当作上线许可。
- 未知酒店字段保留 null / 待核实，不默认 0 分、不伪造设施或认证星级。硬性筛选无法核实的条目不能当作满足。
- 报价标注查询口径，不推断房型、人数、儿童政策、早餐、取消规则、库存或最终订单总价。当前供应方未覆盖的参数明确说明。
- 模拟数据只在显式 mock 模式和测试使用；live 失败报错，不能静默降级。
- 图片保持可信 CDN、HTTPS、私网与重定向防护、大小和像素上限；来源不等于取得独立官网宣传授权。详细约束见[状态与数据契约](STATE_AND_DATA_CONTRACT.md)。

## 设计与交互

以[设计系统](DESIGN_SYSTEM.md)为准。按D-09保留中文品牌、Hero结构、GSAP和明确选择状态，采用A暖色视觉。Typography、色彩与交互参数见现行设计系统。键盘焦点、减少动态效果、手机布局和控件可操作性不能被视觉调整破坏。

不恢复 V1 宣传模块、锚点规划、自动酒店确认、默认景点推荐、分钟级时间和全局 AI 浮窗。涉及目的地、酒店、景点、日期的修改按状态契约处理，不让旧响应覆盖新草稿。

## 按变更验证

| 变更 | 最低实际检查 |
| --- | --- |
| 纯文档 | 内部链接、FR/FZ 引用、来源及权限一致性；无需以运行产品构建冒充文档验证 |
| 类型 / 状态 / 确认 / 异步 | npm.cmd run verify；有针对性的失效、并发、恢复或错误检查 |
| UI / 路由 / 交互 | 上述相关检查，加实际桌面与手机浏览器；回退、直接 URL、控制台和溢出 |
| 供应方 / Agent / MCP | 本地回归加真实服务查询；明确日期、场景和额度边界 |
| 图片 | 来源、缓存复用、重启恢复、临时失败重试、私网 / 重定向限制及浏览器兜底 |
| PDF | 内容对应当前草稿、不改变草稿、中文、分页、渲染与实际下载，含失败重试 |
| 运行稳定性 | 重启、产物生成 / 文件锁、服务退出、前后端连通和外部浏览器的对应复测 |

现有 verify = 类型检查 + 前端测试 + 服务端测试 + 构建。自动化不等于真实供应方验收，接口成功不等于浏览器全流程通过。

npm.cmd run verify:flyai 会做真实查询并可能消耗额度；HTTP 复测要求本地服务运行。保持当前已验证的 FlyAI 专用运行环境，路径 / 版本变化后重新验证，不能只接受成功 JSON 而忽略异常退出。
