# 地点与酒店图片接入

完成日期：2026-10-16 至 2026-10-17（Asia/Shanghai）。原项目 D:\aaa飞猪。

## 当前行为

- 高德地点：MCP text_search 返回的照片优先；没有照片提示时，经服务端调用官方地点详情接口获取同一 POI 的 photos。不会通过网页搜索猜测地点或行政区。
- 飞猪酒店：使用 FlyAI 查询返回的 mainPic。阿里图片 CDN 的原图优先请求 1200 尺寸缩略图，失败后在安全限制内尝试原图。
- 图片流程不调用模型，新增模型 token 为 0。需求解析、交通摘要和酒店推荐仍使用原百炼 Agent，相关模型消耗不在此范围内。供应方接口额度与存储、带宽另计。
- 无图或暂不可取时统一使用有来源记录的风景图，卡片明确显示“通用风景示意图 · 非实景”。没有生成伪装的酒店实拍。

## 缓存

server/image-cache.js 以 amap:<POI ID> / flyai:<酒店 ID> 为键保存首次成功图片。图片与索引位于 data/image-cache/，重启服务后仍沿用。相同 ID 的后续上游主图变化不会覆盖已选图片。

成功图片转换为最大 1200×900 的 WebP，文件名使用内容 SHA-256。网页仅获取 /api/travel/media/<hash>.webp，带一年 immutable 浏览器缓存。缓存索引不能通过 Vite 读取。

同一 ID 的并发查询只下载一次。确认没有候选图片会保存无图状态；网络中断、下载失败只临时使用通用图，后续允许重试。当前为单个 Node 服务实例的本地文件缓存，不包含多实例分布式存储。

## 安全与大图兼容

只接受限定 HTTPS 图片 CDN，禁止凭据 URL、内网地址和未知重定向。单张下载不超过 5MB，图片解码不超过 3600 万像素；不开放任意 URL 代理。服务端保留 Key，不放入网页或图片 URL。

杭州实查遇到两张供应方超大原图，原图被像素限制拒绝。已验证 img.alicdn.com 的 1200 缩略图可以正常转换，再接入自动候选列表。没有关闭像素限制。缩略图仅改写已验证 CDN 的普通图片路径，不修改签名查询地址，不重复改写已缩放路径。

## 验证

自动化：35 项前端测试、18 项服务端测试，共 53 项均通过；正式构建通过。新增验证覆盖持久恢复、并发去重、无图缓存、临时失败重试、私有地址重定向拒绝、可信缩略图路径和前端图片失败替换。

真实数据示例：长沙 → 杭州，2026-10-18 出发，4 天、2 成人；酒店入住 10-18、离店 10-21。图片展示样例临时使用不限价格、不限行政区，保留西湖核心地点。没有选择或预订酒店。

西湖、灵隐寺、西溪国家湿地公园以及推荐商圈通过高德取得照片。FlyAI 酒店图片对应供应方条目，并非用通用图冒充实拍。具体浏览器截图与计数见 artifacts/integration/hangzhou-browser-images.json。
